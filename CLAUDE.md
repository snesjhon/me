# Notes for agents

- Content lives in `site.json`. The owner only edits that file; keep every visible string there, not in code.
- `activity.json` is generated by `scripts/activity.mjs` and refreshed weekly by `.github/workflows/activity.yml`. Never hand-edit it.
- `src/render.mjs` turns both JSON files into HTML at build time (pure function). `src/template.html` holds the `<head>` and all CSS. `src/client.js` is the only browser JS (local clock/status and j/k navigation).
- `site.json` fields:
  - `now`: rows under "Working on". `repo` must match a GitHub repo name so its last-commit date shows.
  - `status`: hourly status lines for the header clock, `from` = hour in `timezone`.
  - `github.exclude`: repos to leave out of the activity feed.
  - `skills` and `education` aren't shown on the page right now; they're kept as data.
- Static files (images, `resume.pdf`, favicon) go in `public/` and are copied to `dist/` as is.
- Check changes with `npm run build`; there are no other dependencies or tests.
